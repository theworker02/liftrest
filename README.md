# liftrest

Lift and reshape rest text streams with deterministic transforms.

**Site:** https://theworker02.github.io/liftrest/

## Install / run

```bash
git clone https://github.com/theworker02/liftrest.git
cd liftrest
node src/cli.js
node --test
```
